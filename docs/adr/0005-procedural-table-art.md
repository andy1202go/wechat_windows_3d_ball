# 台面美术全部程序化生成，不引入素材文件

Status: accepted

台面的所有视觉内容由代码生成：几何用 `Shape` / `ExtrudeGeometry` / `TubeGeometry` 从台面的二维路径数据挤出，贴图用离屏 canvas 绘制后作为 `CanvasTexture` 使用。项目里不放任何图片、模型或音频素材文件。

三个理由：其一，小游戏主包只有 4M，素材是最大的不确定项，程序化生成把素材体积压到零；其二，碰撞几何与视觉几何来自同一份路径数据，不可能出现「看着撞到了却没反应」；其三，改台面即改代码，不需要美术返工，符合「先验证手感」的阶段目标。

## Consequences

- 台面观感上限取决于代码质量，做不出照片级质感。这是接受的取舍——目标是还原 1995 年那张预渲染桌面的**结构**，不是超越它。
- 需要一套「台面声明式数据 → 几何 + 碰撞体 + 贴图」的统一管线，台面用数据描述，路径数据不散落在代码各处。
- 若后续要叠加 AI 生成的底纹，可作为一层独立贴图接入，不触动几何管线。
